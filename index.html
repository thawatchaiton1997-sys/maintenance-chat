วิธีติดตั้งเป็นแอพบนหน้าจอ (PWA App)

เปิดใช้งานเต็มจอเหมือนแอพแชทจริง ไม่ต้องผ่าน App Store

อุปกรณ์นี้รองรับการติดตั้งทันที
กดปุ่มเพื่อเพิ่มไอคอน "แจ้งซ่อมหน้างาน" ลงหน้าจอ
🍎 สำหรับ iPad / iPhone (Safari)
  1. เปิดหน้าเว็บนี้ด้วยเบราว์เซอร์ Safari
  2. แตะปุ่ม แชร์ (Share) ที่แถบเครื่องมือ (ไอคอนสี่เหลี่ยมมีลูกศรชี้ขึ้น)
  3. เลื่อนลงแล้วเลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
  4. กด "เพิ่ม" (Add) จะได้ไอคอนแอพ แจ้งซ่อมหน้างาน บนหน้าจอทันที
🤖 สำหรับ Android / แท็บเล็ต (Chrome)
  1. แตะเมนูจุดสามจุด ⋮ มุมขวาบนของ Chrome
  2. เลือก "ติดตั้งแอป" (Install app) หรือ "เพิ่มลงในหน้าจอหลัก"
  3. กดยืนยันเพื่อเปิดใช้งานแบบเต็มหน้าจอ

เชื่อมต่อเว็บไซต์จริงเข้าแอพแชท (API / Webhook)

ตัวอย่างโครงสร้างข้อมูล JSON และโค้ดสำหรับส่งจากเว็บแจ้งซ่อมของคุณ

เมื่อนำแอพนี้ไปต่อกับฐานข้อมูลกลาง (เช่น Firebase Firestore, Supabase หรือ Node.js + WebSocket) เว็บไซต์แจ้งซ่อมของคุณสามารถยิงข้อมูลรูปแบบนี้เข้าห้องแชทได้ทันทีโดยไม่เสียค่าโควตารายเดือนเหมือน LINE:

1. โครงสร้าง JSON Payload มาตรฐาน 
{
  "machineId": "MC-CNC-04",
  "lineZone": "ไลน์ผลิตที่ 1 (Line 1)",
  "priority": "urgent",
  "symptom": "หัวจับชิ้นงานสไลด์ช้าผิดปกติและมีเสียงลมรั่ว",
  "reporter": "W54H15 น.ส.ไพรริน บัวเปื่อย (หัวหน้างาน)",
  "source": "web-portal"
}
2. ตัวอย่างโค้ด JavaScript fetch() จากหน้าเว็บของคุณ 
async function sendRepairAlertToApp(ticketData) {
  const res = await fetch("https://your-backend-domain.com/api/maintenance/tickets", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "Authorization": "Bearer YOUR_SECRET_WEBHOOK_TOKEN"
    },
    body: JSON.stringify(ticketData)
  });
  return await res.json();
}
3. ตัวอย่าง Google Apps Script (ยิงจาก Google Form / Sheets) 
function onFormSubmit(e) {
  const payload = {
    machineId: e.namedValues["รหัสเครื่องจักร"][0],
    lineZone: e.namedValues["ไลน์ผลิต"][0],
    priority: "urgent",
    symptom: e.namedValues["อาการเสีย"][0],
    reporter: e.namedValues["ผู้แจ้ง"][0]
  };
  UrlFetchApp.fetch("https://your-backend-domain.com/api/maintenance/tickets", {
    method: "post",
    contentType: "application/json",
    payload: JSON.stringify(payload)
  });
}
